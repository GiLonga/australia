# Melbourne in macchina

Mappa interattiva dei posti da vedere intorno a Melbourne, con prezzi, voti e commenti condivisi (Firebase) e il Programma NAZ-ILA.

Sito: https://gilonga.github.io/australia/

- `index.html` – la pagina
- `geo.json` – dati della mappa (costa: OpenStreetMap via geo-maps; strade: Natural Earth)
- `firestore.rules` – regole di sicurezza da incollare in Firebase → Firestore → Regole
